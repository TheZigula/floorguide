## Hazards found while building, for CLAUDE.md and the other instances - 13:24
1. EMBEDDED CHROMA IS ONE PROCESS AT A TIME. While `python -m uvicorn backend.app:app --port 8000` is running, another process that opens ./chroma dies with "Error executing plan: Error sending backfill request to compactor: Failed to get hnsw segment writer". So do NOT run `python backend/ingest.py` while the backend is up - the lifespan already ingests on startup, idempotently - and the eval must go through HTTP rather than opening Chroma itself. Stop the server first if you need a direct index read.
2. ONE CHROMA CLIENT PER PATH PER PROCESS. backend/ingest.py builds its client with Settings(anonymized_telemetry=False); a second client for the same path with different settings raises "An instance of Chroma already exists for ... with different settings", and in my case that silently turned every search into zero hits with only a log line to show it. Match those settings.
3. chromadb 1.5.9 REJECTS `list(embedding_function([q])[0])` - that makes a list of numpy scalars - with "Expected embeddings to be a list of floats or ints, a list of lists, a numpy array, or a list of numpy arrays". Pass the embedding function's output through unconverted.
4. claude-opus-5 RETURNS 400 FOR `temperature` ("temperature is deprecated for this model") and it thinks before answering, with the thinking charged against the same max_tokens - a 200-token cap truncated the answer mid-sentence. _chat learns which models refuse temperature on the first 400 and asks for 2000 tokens. Also: a live turn costs about $0.06-$0.09 on opus, so the default per-run cap of $0.50 is roughly five turns.
5. TWO SMALLER ONES. A logging Filter that sets `record.args = ()` breaks uvicorn's AccessFormatter, which unpacks five values from args, and kills the access log; wrap each handler's FORMATTER instead. And bare `load_dotenv()` raises an AssertionError when python is fed from stdin (it walks the caller's stack frame) and looks in the process cwd, which uvicorn can change - always pass the repo-root path.
